# Bookify

منصة ويب لحجز الخدمات المهنية، تربط مقدمي الخدمات بالعملاء. يتصفح العميل الخدمات ويحجز موعداً متاحاً ويدفع إلكترونياً، ويدير مقدم الخدمة خدماته وحجوزاته، ويشرف المدير على المنصة كلها.

## الأدوار
- **العميل (Client):** تصفح التصنيفات والخدمات، حجز موعد ضمن الأوقات المتاحة، الدفع عبر Stripe، إلغاء الحجز، تقييم الخدمة بعد إتمامها، فتح تذاكر دعم، وإدارة الملف الشخصي.
- **مقدم الخدمة (Staff):** إنشاء الخدمات وتعديلها (وتخضع التغييرات لموافقة الإدارة)، ومتابعة الحجوزات والعملاء والتقييمات، ولوحة تحكم خاصة.
- **المدير (Admin):** إدارة المستخدمين والتصنيفات والخدمات، ومراجعة طلبات الإضافة والتعديل بالموافقة أو الرفض، ومتابعة الحجوزات والإحصائيات والتقارير، وإدارة الأسئلة الشائعة ومعلومات التواصل وتذاكر الدعم.

## الوظائف الأساسية
- **التسجيل والدخول:** تسجيل بالبريد مع رمز تحقق OTP من 6 أرقام صالح لمدة 5 دقائق، ودخول بـ JWT مع Refresh Token صالح لمدة 7 أيام، واستعادة كلمة المرور.
- **الحجز:** يُستبعد الوقت المحجوز مسبقاً، مع حد أدنى للحجز المسبق وفحص ساعات العمل. حالات الحجز: معلّق، مؤكد، مرفوض، مكتمل، ملغى.
- **الدفع:** Stripe Checkout وPaymentIntent مع نقطة Webhook. حالات الدفع: معلّق، ناجح، فاشل، مسترد.
- **الإشعارات:** إشعارات داخل التطبيق، وإشعارات فورية عبر Firebase Cloud Messaging، مع مهمة خلفية تنظف الإشعارات القديمة.
- **الصور:** رفع صور الخدمات والملفات الشخصية عبر Cloudinary.
- **الجودة والأمان:** حماية حسب الدور، وRate Limiting، وSecurity Headers، ومعالجة أخطاء مركزية، والتحقق من المدخلات بـ FluentValidation، وسجلات Serilog، وSwagger.

## البنية التقنية

| المشروع | الدور |
|---|---|
| `Bookify.Domain` | الكيانات والتعدادات وقواعد الحجز والخدمة |
| `Bookify.Application` | منطق الأعمال وDTOs والمدققات وAutoMapper |
| `Bookify.Infrastructure` | EF Core وPostgreSQL وIdentity وJWT وStripe وCloudinary وFirebase والبريد |
| `Bookify.API` | واجهات REST للأدوار الثلاثة |
| `Bookify.Client` | واجهة Blazor WebAssembly مع Blazorise وTailwind CSS |
| `Bookify.AppHost` و`Bookify.ServiceDefaults` | تشغيل .NET Aspire وOpenTelemetry |

**التقنيات:** .NET 10، ASP.NET Core Web API، Blazor WebAssembly، PostgreSQL.

## الإعداد المحلي
1. عيّن المتغيرات الموجودة في `.env.example` في بيئة التشغيل (مثل لوحة Render)، أو ضعها محلياً في `Bookify.API/appsettings.Development.json`. متغيرات البيئة لها الأولوية على ملفات الإعدادات.
2. أو أنشئ `Bookify.API/appsettings.json` محلياً بنسخ `Bookify.API/appsettings.example.json` وتعبئة القيم. هذا الملف غير متتبع في git.
3. نقطة التشغيل المحلية هي مشروع `Bookify.AppHost` (.NET Aspire).

لا ترفع أي ملف يحتوي على مفاتيح أو كلمات مرور إلى المستودع.

## الحالة
مشروع في مرحلة تطوير نشطة. لا توجد اختبارات آلية ولا CI حالياً.
